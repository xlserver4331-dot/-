# AI 全流程 MMD 转 CS2 技能

本仓库提供面向支持 `SKILL.md` 的 AI Agent 的转模流程技能，用于将 MMD PMX/PMD 角色制作成 CS2 第三人称玩家模型及独立第一人称手模。技能要求 AI 执行模型准备、制作、检查、修复、编译、部署和本地验证，并如实报告未完成的步骤。

## 核心要求

- 开始制作时由用户选择主体高度：接近本机默认探员主体高度、自定义高度、统一缩放倍数或保留原高度。头发、帽子、角、翅膀等装饰不计主体高度，但计入完整包围盒。
- 保留原模型的身体骨骼、装饰骨骼、关节位置与身体比例。通过独立驱动层适配动画，避免为贴合官方骨架拉长身体或移动原关节。
- 第一人称手模从原模型取材，作为独立资源制作、绑定和验证。
- 检查第三人称和第一人称的持枪、射击、换弹、检视等动作，以及网格破洞、骨骼错位、异常拉伸、穿模、装饰随动和死亡动作。
- 编译与部署面向用户授权的本地私人测试环境；实际加载和实机验收需要当前可用的工具及运行环境。

## 使用

将 [`ai-mmd-cs2-pipeline`](ai-mmd-cs2-pipeline/) 目录安装到 AI 工具的技能目录，或在支持技能的环境中指定该目录。制作前提供有使用权的 MMD 模型及相关贴图，并按提示选择高度方案。

- [技能入口](ai-mmd-cs2-pipeline/SKILL.md)
- [详细制作与部署流程](ai-mmd-cs2-pipeline/references/workflow.md)
- [检测、修复与交付](ai-mmd-cs2-pipeline/references/qa-and-delivery.md)

本仓库提供的是 AI 工作流程和验收要求，不包含一键完成转模的独立程序，也不代表任何具体模型已经通过游戏内测试。实际结果取决于源模型、工具链、引擎兼容性和本地运行验证。
