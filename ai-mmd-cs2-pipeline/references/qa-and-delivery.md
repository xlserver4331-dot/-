# 检测、修复与交付

## 证据与结论规则

每项单独记录 PASS、FAIL、PENDING 或 N/A、判定依据和执行日期；列出源模型、候选及运行产物的路径与哈希，环境、动作、武器、帧、视角、问题部位、测量值、截图和日志。PASS 必须有该项实际证据；缺资源、没有运行、不能观察或结果不确定一律 PENDING，并说明原因。N/A 要说明为何不适用。不要把脚本运行成功、编译成功、截图正常或 bot 换模当作本机玩家双视角通过。

AI 自行收集源和候选相同角度的图像、rest 骨架及动画逐帧数据。自动指标用于定位，结合图像和实际运动判断；阈值按角色尺度、源模型误差与目的制定并记录，不将任意百分比当作通用标准。需要观察遮挡时改变视角、局部隔离网格或使用线框；静态检查不能替代动作检查。

## 原比例、骨骼和高度

1. 固定源与候选的单位、上轴、根变换及统一缩放，列出用户选择、主体与装饰分类、原高度、目标/参考高度、实测高度和倍率。默认探员高度需同法从本机资源实测。装饰不计入主体高度，但加入全模型静态与动态 bounds。
2. 对照源骨名及映射、父子关系、rest 局部矩阵、头尾、骨长、关节位置、骨轴、权重与装饰骨链；先剔除统一整体变换，再比较差异。识别未导出、错父级、镜像、骨轴不一致、未受驱动的骨骼。保留原源骨关节和部位比例，不以官方骨位置或长度为目标。
3. 对比前、侧、背和关键关节近景；对差异大的顶点、骨链按对象与顶点/骨名输出，区分导入坐标变换与真实改动。检查新驱动层是否只改变姿态而非静默改变源 rest、骨长和蒙皮。不可避免的兼容变更必须列出原因和可见影响。

## 网格与蒙皮

- 静态扫描边界边、非流形、退化面、重复顶点、法线翻转、未赋权或异常权重；对衣袖、领口、裙摆、眼口等有意开口做基线标注，边界边数量不是破洞结论。
- 对源与候选一致动作采样，包括弯曲极值、动作切换和高速运动；定位肩、腋下、肘、腕、腰、胯、膝、踝、手指及衣服接缝，检查皮肤裂口、接缝分离、翻面、异常拉丝和身体穿出。记录动作、帧、相机角度与顶点或骨骼。
- 对照源 UV、贴图、材质槽、透明排序、双面、法线和描边；查看移动中透明物遮挡和发丝边缘。自动焊接或补面只作用于已确定为缺陷的区域，在副本保留 UV 接缝、法线、材质及权重；重新检查相邻帧。

## 变形、持枪和动画覆盖

分别在编辑环境和可用游戏环境检查以下项目，保存动作名、起止及采样帧、观察视角、缺失项目。至少检查动作起始、结束、姿势极值和过渡；异常区域加密逐帧，不能仅抽一帧宣布动画通过。

| 范围 | 操作和判定重点 |
| --- | --- |
| 全身 TP | 待机、走跑、急停、转身、跳跃、落地、蹲伏、蹲走、瞄准、射击、切枪、换弹、受击。检查肩肘腕、颈、髋膝踝及手指关节是否错位、扭转、拉长、塌陷或跳动；左右对称动作分别检查。 |
| TP 武器 | 对可用的手枪、步枪、狙击枪、冲锋枪、霰弹枪、机枪、刀具/投掷物分别记录覆盖情况；检查主手握柄与扳机、辅助手与护木、枪托、武器朝向、切换和换弹接触。目标无法触及先调整旋转、控制层或合理的武器相对偏移，不能拉长四肢。 |
| FP 独立手模 | 对实际提供的武器类别检查待机、射击、移动、切换、换弹和检视，查看左右手握持、扳机手指、辅助手、袖口、视角裁切、接缝、皮肤和贴图；证明加载的是独立的同源手模。 |
| 装饰与动态 | 发丝、裙摆、饰带、翅膀等原装饰骨及其权重，检查跟随、抖动、穿模、拉伸、极端姿态和重生后的恢复。记录源物理与目标实现差异；原平台物理不视为已自动兼容。 |
| 死亡与边界 | 受击、死亡过渡、ragdoll、复活；分别检查物理、碰撞、hitbox、静态和动态渲染 bounds。视觉轮廓正常不证明 hitbox 正确。 |

## 编译、加载和实机

分别核对 TP 与 FP 的导出时间、哈希、ModelDoc 引用、编译命令/退出码、日志与编译产物；检验资源依赖完整和实际加载的版本，避免旧导出或旧缓存。记录当前游戏、工具、插件版本与启动方式。实际在私人本地房间确认资源挂载与预缓存，再验证本机玩家 Pawn 的 TP 换模、FP 手模替换、各自武器动作、死亡和重生；有需要时可加 bot 做额外检查，但不代替玩家。收集控制台日志、可复现步骤和画面。若加载机制、工具或环境不可用，保留 PENDING 和具体阻塞。

## 缺陷闭环与失效规则

每个问题记录编号、严重程度、复现条件、源模型是否已有、根因假设和对比证据。优先在复制版本中最小修改权重、局部约束、映射或接缝，保留原骨与比例；每次修改记录输入/输出版本并复测原失败动作、相邻动作和可能受影响的部位。连续尝试无法可靠修复时保留最佳可回滚候选，说明剩余问题，不伪称通过。

修改高度或整体变换后重测尺寸、比例、动作、bounds 和部署；修改源网格或权重后重测相关变形并核对 FP 同源性；修改骨架/驱动后重跑关联动作；修改 FP 后重新导出、编译并实测 FP；修改资源引用或部署后重新核对加载版本。旧版本证据不能证明新版本通过。

## 交付清单

交付原始文件清单与哈希、未改基线、可编辑工程、TP/FP 分别的源和导出、材质贴图与许可允许的依赖、CS2 content/game 编译资源、实际引用与哈希、安装条件、部署文件清单及备份回滚步骤。报告列出用户选定高度及实测、主体/饰件分类、源骨保留与必要变更、武器和动作覆盖、问题及修复、截图日志、未完成项。依次区分已制作、已编译、已部署、已加载和已实机通过，不把模拟或尚未执行的结果写成成功。
